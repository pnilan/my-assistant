# 0013 — Error UX

## Context

When the agent or a tool fails, the user hears the result via HomePod. Options
trade off informativeness vs friction.

## Options

- **Speak the error verbatim** — most informative, can be jarring.
- **Speak a canned apology** ("sorry, something went wrong, try again") —
  friendly but opaque.
- **Retry silently once, then apologize** — balances but adds latency.
